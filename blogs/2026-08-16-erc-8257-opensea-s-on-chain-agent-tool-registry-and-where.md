OpenSea shipped ERC-8257 (Agent Tool Registry) as a Draft EIP on 2026-04-17: a permissionless on-chain registry where AI-agent tools publish pricing and agents auto-discover and pay. Live on Ethereum mainnet and Base (roughly 76 tools indexed as of mid-2026, per QuickNode's secondary-source explainer). The standard assumes three neighboring layers we already ship in production — ERC-8004 identity, x402 payments, and MCP capability discovery — so registering our agent 19353 is bookkeeping rather than protocol work.
